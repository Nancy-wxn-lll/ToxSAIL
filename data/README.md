# Data Cache

This directory contains small cached public toxicity benchmark tables used by the experiment scripts. The files are included to make the GitHub experiment package runnable without requiring network access to TDC.

| File | Dataset name used by scripts | Source benchmark |
| --- | --- | --- |
| `herg.tab` | `hERG` | TDC Tox hERG |
| `ames.tab` | `AMES` | TDC Tox AMES |
| `dili.tab` | `DILI` | TDC Tox DILI |
| `ld50_zhu.tab` | `LD50` | TDC Tox LD50_Zhu |
| `tox21.tab` | `Tox21` | Tox21 multi-label toxicity benchmark |
| `clintox.tab` | `ClinTox` | ClinTox toxicity benchmark |
| `skin_reaction.tab` | `Skin-Reaction` | TDC Tox Skin_Reaction |
| `carcinogens_lagunin.tab` | `Carcinogens` | TDC Tox Carcinogens_Lagunin |

If these cached files are not present, `src.data.datasets.load_toxicity_data` attempts to load the corresponding dataset through PyTDC.

All downstream splits are generated by the local scaffold/random split implementation in `src/data/splitting.py`; the cached tables are unsplit input data.
